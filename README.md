## 9929 这条线路，改善的是晚高峰而不是峰值

AS9929 是中国联通的精品网骨干。三网回程的走向大致是：电信用户回程走联通 9929 再回电信 163，联通用户直连 9929，移动用户走 9929 再转移动 CMI。实际体感上的收益是高峰期丢包少、晚高峰延迟抖动小，对建站、远程办公、代理中转这类对稳定性敏感的场景有用。

它和另外两条常被拿来比较的线路定位不同。4837 是联通 A 网，带宽给得大、价格低，9929 一般被认为质量高一档，价格也贵一档。CN2 GIA 在电信方向的回程质量更极致，价格也更贵。三条线不少商家同时在卖，别把“联通 9929”和“三网 CN2 GIA”当成同一档东西，价差不大时，该看的是你的访客和你在哪个运营商。

## 一台真实 9929 机器的延迟数据，能纠正两个预期

VPS.Taxi 的 LAX.9929（$3.00/月，1×Xeon Gold 6138、0.5GB 内存、9.7GB 磁盘、300Mbps 端口、500GB/月流量）有公开的中国各地中位延迟数据：电信 137–166ms，联通 162–182ms，移动走 CMIN2 落在 129–168ms。

三个细节值得记住：

- 北京联通 178ms，比同一台机器上电信的 160ms、移动的 153ms 都高。
- 湖北联通 167ms，走的是 4837，不是 9929。
- 移动的 CMIN2 在多数城市是三者里最低的，上海 129ms、浙江 131ms。

所以“9929 是联通精品网”推不出“联通用户用它最快”。省内出口、跨网互联、回程具体落到哪条 AS，都会改写结果。别人测出来的数字只能当上限参考，你家宽带才是决定项。这也是我建议第一台按月付的原因：$3 的试错成本，比年付省下来的钱重要得多。

## 按用途选档：哪一档够用，哪一档是浪费

**轻量代理、个人博客、几个人的小站。** 1 核 1G 够用，别加钱。流量 200–500GB/月 覆盖绝大多数个人站，端口 50Mbps 以上的意义不大。这一档不需要买 2 核，也不需要买 CN2 GIA。LightLayer 的 Startup 在这个场景里唯一的短板是不可升级，如果你半年后可能加站，就从 Pay As You Go 起。

**TikTok 运营、流媒体解锁、跨境电商。** 该付钱的是 IP 属性，不是核心数。非原生 IP 便宜，但被判定为数据中心的概率高；双 ISP 家宽住宅原生 IP 通常贵 200 元/年这个量级，对这类业务是值得的。核心数在这一档基本不构成瓶颈，4 核 4G 的豪华版对单人运营是浪费。

**长期挂机、大流量同步、不想被配额打断。** 先看带宽再看流量。20Mbps 跑满一天约 200GB，一个月 6TB 上下，够不够自己算；50Mbps 是 500GB/天这个量级。这一档最容易花冤枉钱：为了“不限流量”买 20Mbps 的窄带宽，结果每天慢得难受。反过来说，LightLayer 那三档不限流量配 100–200Mbps 端口，在这个用途下的性价比比在轻量场景里更高。

**跑 AI 服务（ChatGPT、Claude 一类）。** 看的是 IP 地域和纯净度，欧洲 IP 在部分服务上比美国 IP 宽松，双栈原生 IPv6 对纯 IPv6 环境兼容性更好。这条需求跟 9929 关系不大，别为了线路名多花钱，先把 IP 属性确认清楚。

## 下单前必须确认的四件事

**计费周期和续费价。** 促销价和续费价经常不是一个数。问清楚第二年按什么价续，比首年便宜多少重要得多。

**线路实走。** 让客服给一条从机房到你所在城市的回程路由，看是不是真的 AS9929。前面那组延迟数据已经说明了，同一台机器上联通也可能绕去 4837。只看“9929”三个字不够。

**IP 属性。** 原生、住宅、数据中心，三种在风控面前是三张不同的脸。建站无所谓，做账号运营就是生死线。

**退款窗口。** 有几天无理由退款，就用这几天集中测晚高峰：20:00–23:00 的丢包率和延迟抖动，比白天的数字有用得多。
